# Minha Rotina – Frontend

Interface do dashboard (React + Vite + TypeScript).

- **Desenvolvimento:** `npm run dev` (use `VITE_API_URL=http://localhost:3000/api` no `.env`)
- **Build:** `npm run build` → saída em `dist/`

Veja o [README principal](../README.md) na raiz do projeto para setup completo e deploy.
